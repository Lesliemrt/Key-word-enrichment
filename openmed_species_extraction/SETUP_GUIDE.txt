OpenMed Species Extraction - Setup Guide
==========================================

QUICK START (3 steps):
1. Install Python dependencies: pip install -r requirements.txt
2. Run the tool: python openmed_species_extraction.py
3. Check the output file: openmed_improved_fixed_Data_cleaned.csv

DETAILED INSTRUCTIONS:

Prerequisites:
- Python 3.7 or higher
- Internet connection (for downloading model and GBIF validation)

Step 1: Install Dependencies
---------------------------
Open terminal/command prompt in this folder and run:
    pip install -r requirements.txt

This will install:
- pandas (data processing)
- transformers (AI model)
- torch (deep learning framework)
- requests (API calls)
- numpy (numerical computing)
- huggingface-hub (model downloading)

Step 2: Run the Tool
-------------------
    python openmed_species_extraction.py

What happens:
- First run: Downloads OpenMed model (~400MB) - this takes a few minutes
- Subsequent runs: Uses cached model - much faster
- Processes Data_cleaned.csv (45 entries)
- Validates species against GBIF database
- Shows progress and results in terminal

Step 3: Check Results
--------------------
Output file: openmed_improved_fixed_Data_cleaned.csv

New columns added:
- predicted_species: AI-extracted species names
- Taxon: List format of species
- Accepted Names: Species found in GBIF with links
- Misspelled Names: Corrected species names
- Unrecognised Names: Species not found in GBIF

CUSTOMIZATION:

To use your own CSV file:
1. Replace Data_cleaned.csv with your file
2. Edit line 11 in openmed_species_extraction.py:
   INPUT_CSV = "your_filename.csv"
3. Make sure your CSV has a text column (Description, Text, etc.)

TROUBLESHOOTING:

Problem: "No module named 'transformers'"
Solution: Run: pip install -r requirements.txt

Problem: Slow first run
Solution: Normal - model downloads once (~400MB)

Problem: GBIF API errors
Solution: Check internet connection, tool includes rate limiting

Problem: Out of memory
Solution: Close other applications, restart computer

PERFORMANCE EXPECTATIONS:

On the sample dataset (45 entries):
- Precision: 57.1% (good accuracy)
- Recall: 30.3% (finds 1/3 of species)
- Processing time: ~2-3 minutes after model loads

FILES INCLUDED:

- openmed_species_extraction.py (main script)
- Data_cleaned.csv (sample input data)
- openmed_improved_fixed_Data_cleaned.csv (sample output)
- requirements.txt (dependencies)
- README.md (detailed documentation)
- SETUP_GUIDE.txt (this file)

SUPPORT:

For issues or questions, check the README.md file for more technical details.

The tool uses the OpenMed biomedical AI model to automatically find species names in scientific text and validate them against the global GBIF taxonomic database.
